## Tecnologias e práticas

O percurso público inclui HTML, CSS, JavaScript, TypeScript, React, Node.js, Python, Bash, Linux, SQL, PostgreSQL, Git, documentação, testes, autenticação JWT, controle de acesso com RLS, redes TCP/IP e IPv6, além de fundamentos de vulnerabilidades e proteção contra phishing.

## Executar localmente

Como o projeto é uma página estática, basta abrir `index.html` no navegador ou servi-lo com qualquer servidor HTTP local. Não há backend, banco de dados ou segredo necessário para visualizar a página.
