### 1. Plataforma Digital para Comércio de Materiais
**E-commerce Full-Stack B2B com Gestão Avançada**

Uma plataforma completa de comércio eletrônico desenvolvida do zero, focada em B2B com funcionalidades enterprise.

**Tecnologias:** Next.js 14 • TypeScript • Node.js • Express • Supabase • PostgreSQL • JWT • Framer Motion • PWA

**Funcionalidades Principais:**
- Catálogo dinâmico com busca avançada e filtros por categoria
- Carrinho de orçamentos com envio automático via WhatsApp
- Painel administrativo completo para gestão de pedidos, produtos e parceiros
- Autenticação JWT com Row Level Security (RLS) — segurança desde o design do banco
- PWA instalável com animações premium e design responsivo
- Experiência de usuário otimizada para desktop e mobile

**Impacto:** Plataforma escalável pronta para produção com arquitetura segura e performática.

### 2. Xodó Digital — Sistema de Pedidos para Padaria
**Delivery & Gestão em Tempo Real com Notificações Instantâneas**

Sistema completo de gestão de pedidos para padarias com notificações em tempo real, cálculo inteligente de taxas e programa de fidelidade.

**Tecnologias:** Node.js • Express • Socket.IO • node-cron • Geolocation API • WhatsApp API • JavaScript

**Funcionalidades Principais:**
- Notificações em tempo real via Socket.IO — admin e cliente sincronizados instantaneamente
- Cálculo de taxa de entrega por geolocalização usando fórmula de Haversine
- Sistema de cupons de desconto e pontos de fidelidade
- Avaliações de pedidos e cancelamento com devolução automática
- Backup automático de dados e relatórios financeiros via Cron Job
- Dashboard intuitivo para gestão operacional

**Impacto:** Aumenta eficiência operacional e satisfação do cliente com automação completa.

**Funcionalidades Principais:**
